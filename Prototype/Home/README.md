# Roomly home prototype

Open `index.html` in a modern browser. No installation, internet connection, or server is needed. Keep the sibling `../Login/` folder in place for sign-in navigation.

Matches the Login prototype's indigo `#35449c`, button blue `#4757c8`, pale lavender, Segoe UI font fallback, rounded controls, house illustration style, and Roomly wordmark.

Includes a responsive hero with an illustrated sample bill, benefits, onboarding steps, expandable FAQs, a privacy dialog, mobile navigation, and links to the existing login prototype. All sample amounts are illustrative and have no assumed currency. No authentication, payment processing, tenant data collection, remote assets, or analytics are connected.

Before production, connect real authentication, verify database permissions, provide a full privacy notice, and replace prototype/sample information as appropriate.
